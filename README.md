# movie-watchlist
# Link -- https://movie-watch-list-web-application.netlify.app/

**MovieFlexia** is a sleek and responsive movie watchlist web app built with **React.js**, using the **OMDb API** to fetch real-time movie data. Users can search for movies, view details, and manage a personalized watchlist.

## 🚀 Features

- 🔍 Real-time movie search using OMDb API
- ➕ Add/remove movies to/from your watchlist
- 💾 Persistent data with localStorage
- 📱 Fully responsive and mobile-friendly UI
- ⚡ Fast and dynamic rendering using React

## 🛠️ Tech Stack

- React.js (with Hooks)
- CSS (or Tailwind, if used)
- JavaScript (ES6+)
- [OMDb API](https://www.omdbapi.com/)
- LocalStorage
